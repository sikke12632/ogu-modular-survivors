# Performance budget

## 목표

- 중급 노트북/태블릿: 60 FPS 목표
- 저사양 모바일: 30 FPS 아래로 장시간 머물지 않음
- 30분 반복 플레이 후 활성 객체와 메모리가 계속 증가하지 않음

## 적용된 장치

- 160px 셀 공간 해시로 범위 탐색
- 적/투사체/픽업 Phaser Group 재사용
- 프레임 델타 상한
- 화면에서 먼 적 AI 저빈도 처리
- SpawnBudget과 품질 계수
- 2초 FPS 표본을 이용한 high/medium/low 자동 조절
- 피해 숫자와 이펙트 확률/개수 제한
- 경험치 풀이 찼을 때 기존 보석에 값 합치기

개발 HUD 오른쪽 위에서 FPS, 활성 적 수, 품질 등급을 확인할 수 있습니다.
