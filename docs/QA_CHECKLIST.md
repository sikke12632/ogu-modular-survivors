# QA checklist

## 핵심 흐름

- [ ] 세 캐릭터 모두 새 게임 시작 가능
- [ ] 키보드 대각선 이동 속도가 축 이동보다 빠르지 않음
- [ ] 터치 조이스틱을 놓으면 즉시 정지
- [ ] Q/터치 필살기가 게이지가 찼을 때만 발동
- [ ] 레벨업 선택 후 전투가 정상 재개
- [ ] 보물상자 선택 후 전투가 정상 재개
- [ ] 일시정지 중 전투 시간이 흐르지 않음
- [ ] 저장 후 새로고침하고 이어하기 가능
- [ ] 승리/패배 후 활성 판 저장이 삭제됨

## 콘텐츠

- [ ] 12개 무기를 신규 획득하고 Lv.5까지 강화 가능
- [ ] 각 무기가 눈에 띄게 다른 패턴으로 공격
- [ ] 무기 Lv.5 + 지정 보조 능력 + 보물상자에서 진화
- [ ] 일반 적 12종과 엘리트 4종 역할 확인
- [ ] 5/10/14.5분 보스의 경고와 상태 변화 확인
- [ ] 30콤보 어셈블, 미션 성공/실패, 원거리 보물상자 확인

## 브라우저/PWA

- [ ] Chromium 데스크톱
- [ ] Firefox 데스크톱
- [ ] WebKit/Safari
- [ ] Android 터치 가로 화면
- [ ] iOS/iPadOS Safari
- [ ] 첫 온라인 접속 뒤 오프라인 재실행
- [ ] 전투 중 새 서비스 워커가 강제로 새로고침하지 않음

전체 타임라인은 `/?dev=1`로 약 1분 안에 점검할 수 있습니다.
