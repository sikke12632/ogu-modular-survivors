# QA checklist

## 핵심 흐름

- [ ] 세 캐릭터 모두 새 게임 시작 가능
- [ ] 키보드 대각선 이동 속도가 축 이동보다 빠르지 않음
- [ ] 터치 조이스틱을 놓으면 즉시 정지
- [ ] Q/터치 필살기가 게이지가 찼을 때만 발동
- [ ] 레벨업 선택 후 전투가 정상 재개
- [ ] 보물상자 선택 후 전투가 정상 재개
- [ ] 일시정지 중 전투 시간이 흐르지 않음
- [ ] 저장 후 새로고침하고 이어하기 가능
- [ ] 이어하기 후 플레이어 위치·미션·콤보·보물상자가 유지됨
- [ ] 보스 전투 중 이어하기 후 위치·행동 단계·공격 쿨다운이 유지되고 보스가 한 마리만 존재
- [ ] v1 저장이 v2 체크포인트로 자동 이관됨
- [ ] 손상되거나 알 수 없는 버전의 저장은 안전하게 거부됨
- [ ] IndexedDB 쓰기 실패 시 localStorage 대체 체크포인트로 이어하기 가능
- [ ] IndexedDB 삭제 실패 뒤에도 완료·포기한 판이 다시 나타나지 않음
- [ ] 저장소가 모두 실패하면 오류 안내가 나오고 저장 종료가 중단됨
- [ ] 승리/패배 후 활성 판 저장이 삭제됨

## 콘텐츠

- [ ] 12개 무기를 신규 획득하고 Lv.5까지 강화 가능
- [ ] 각 무기가 눈에 띄게 다른 패턴으로 공격
- [ ] 무기 Lv.5 + 지정 보조 능력 + 보스 보물상자에서만 진화
- [ ] 일반 상자가 남아 있어도 보스 처치 시 보스 상자로 교체
- [ ] 일반 적 12종과 엘리트 4종 역할 확인
- [ ] 5/10/14.5분 보스의 경고와 상태 변화 확인
- [ ] 30콤보 어셈블, 미션 성공/실패, 원거리 보물상자 확인

## 브라우저/PWA

- [ ] Chromium 데스크톱
- [ ] Firefox 데스크톱
- [ ] WebKit/Safari
- [ ] Android 터치 가로 화면
- [ ] iOS/iPadOS Safari
- [ ] 첫 온라인 접속 뒤 오프라인 재실행
- [ ] 전투 중 새 서비스 워커가 강제로 새로고침하지 않음

전체 타임라인은 `/?dev=1`로 약 1분 안에 점검할 수 있습니다. CI는 `/?dev=1&timeScale=80`과 개발 전용 QA 브리지를 사용해 느린 실행 환경에서도 같은 흐름을 결정적으로 완료합니다.

## 자동화된 장기 검증

- [x] `/?dev=1`에서 최종 보스까지 15분 전체 타임라인 자동 플레이
- [x] 모바일 터치 조이스틱 드래그 이동과 손을 뗀 뒤 즉시 정지
- [x] 서비스 워커 설치 뒤 네트워크를 끊고 PWA 새로고침
- [x] 저장·이어하기, 재도전 초기화, 메뉴 20회 재생성

GitHub Actions는 `main` 대상 PR에서 단위 테스트, PWA 빌드와 전체 Playwright 검증을 실행합니다. Pages 배포는 저장소가 공개 상태일 때만 검증된 `dist` 산출물로 실행합니다.
