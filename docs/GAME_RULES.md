# Game rules

## 목표

3명 중 한 캐릭터를 선택해 15분 아레나를 진행합니다. 5분, 10분, 14분 30초에 보스가 등장하며 최종 군주를 쓰러뜨리면 승리합니다.

## 성장

- 적이 떨어뜨린 경험치 보석을 획득하면 레벨이 오릅니다.
- 레벨업 때 무기 신규 획득, 기존 무기 강화, 보조 능력 중 3개가 제시됩니다.
- 무기 슬롯과 보조 능력 슬롯은 각각 6개입니다.
- 무기 Lv.5 + 지정 보조 능력 + 보물상자를 만족하면 진화합니다.

## 전투 이벤트

- 처치를 3.5초 안에 이어가면 콤보가 유지되고 점수 배율이 오릅니다.
- 한 콤보에서 30처치를 달성하면 네 동료가 5초 동안 사격하는 오구 어셈블이 발동합니다.
- 미션은 처치, 생존, 무피격, 수집, 엘리트 처치 중 하나입니다.
- 일반 보물상자는 플레이어에게서 420px 이상 떨어진 위치에 주기적으로 등장합니다.
- 필살기 게이지는 피해를 주면 채워지고 캐릭터마다 다른 필살기가 발동합니다.

## 종료

- HP가 0이면 패배입니다.
- 최종 군주를 처치하면 승리입니다.
- 결과는 로컬 기록에 반영되고 현재 판 저장은 삭제됩니다.
