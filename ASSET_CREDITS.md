# Asset credits

The current prototype contains no downloaded raster sprites, music, sound samples, or third-party fonts.

- The application icon is an original SVG in this repository.
- Characters, enemies, projectiles, pickups, telegraphs, and effects are drawn at runtime with Phaser primitives.
- Short sound effects are synthesized at runtime with the Web Audio API.

This keeps the prototype redistributable and makes the later Ogu skin pass a texture/data replacement rather than a combat rewrite.
